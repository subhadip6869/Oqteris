# Oqteris Format Compatibility Matrix & Technical Specifications

## 1. Supported Document Format Overview

Oqteris is exclusively a dedicated PDF reader and editor. Its primary format is the **Portable Document Format (PDF)** conforming to ISO 32000 standards.

| Format | Standard Specification | MIME Type | Read | Edit / Annotate | Cryptographic Verification |
|---|---|---|:---:|:---:|:---:|
| **PDF** | ISO 32000-1 (PDF 1.0–1.7)<br/>ISO 32000-2 (PDF 2.0) | `application/pdf` | **Yes** | **Yes** | **Yes** (CMS / PKCS#7) |

---

## 2. PDF Viewing & Navigation Specifications

### 2.1 Document Structure & Page Layout
- **Page Tree Navigation**: Reads `/Pages` dictionary tree from the PDF catalog. Supports documents with single-page and multi-page layouts.
- **Continuous Vertical Layout**: Renders document pages vertically with realistic page boundaries, spacing gutters, and responsive resizing.
- **Arbitrary Zoom & Scaling**: Supports zoom levels from 25% to 400%, plus quick presets (Actual Size 100%, Zoom In, Zoom Out) with hardware-accelerated rendering.
- **Page Rotation**: Supports on-the-fly page rotation (0&deg;, 90&deg;, 180&deg;, 270&deg; clockwise) preserved during navigation.
- **Password-Protected Documents**: Prompts for password via `PasswordPromptDialog` when encrypted with standard PDF security handlers (40-bit RC4, 128-bit RC4/AES, and 256-bit AES).

### 2.2 Navigation & Outline
- **Interactive Thumbnails Drawer**: Asynchronously generates high-resolution page thumbnails in a collapsible sidebar for rapid navigation.
- **Document Bookmarks / Outline Tree**: Parses hierarchical `/Outlines` entries and destinations, allowing one-click navigation to chapters and sections.
- **Interactive Text Search**: Full-text search across document content streams with match counting, active match selection, and Next/Previous navigation.

## 3. Cryptographic Digital Signature Specifications

### 3.1 Signature Containers & Standards
- **Standards**: Adobe PPKLite detached signatures (`adbe.pkcs7.detached`), CMS / PKCS#7 detached signatures (`ETSI.CAdES.detached`).
- **Digest Algorithms**: SHA-256, SHA-384, SHA-512, SHA-1 (with deprecation warning).
- **Asymmetric Cryptosystems**: RSA (1024, 2048, 3072, 4096-bit keys), ECDSA (NIST P-256, P-384, P-521 curves).

### 3.2 Byte-Range Integrity Verification
- **Byte Range Parsing**: Extracts the `/ByteRange [offset0 length0 offset1 length1]` array from each signature dictionary.
- **Full Coverage Requirement**: Enforces that the byte range starts at byte 0 and spans continuously to the end-of-file (excluding the `/Contents` hex string).
- **Tampering Detection**: Detects any appended bytes, incremental updates, or post-signing modifications. Documents with post-signing modifications are immediately flagged with a **Red** warning.

### 3.3 Visual Appearance Rewriting
- **In-Memory Appearance Rewriting**: In documents containing layered appearance streams (`n0`–`n4` XObjects, as generated by Adobe Acrobat or iText), Oqteris inspects real-time cryptographic verification results and rewrites the visual appearance in memory:
  - Green tick badge for valid and trusted signatures.
  - Yellow question mark badge for valid but untrusted signatures.
  - Red cross badge for mathematically invalid or tampered signatures.
- **Non-Destructive**: Appearance rewriting is performed exclusively in memory for display; the underlying document on disk remains unmodified.

### 3.4 X.509 Certificate Chain Validation & Trust Store
- **Chain Building**: Extracts the signer's X.509 certificate and reconstructs the intermediate certificate path from embedded CMS certificates.
- **Validity Periods**: Validates `notBefore` and `notAfter` timestamps against the signing time or embedded RFC 3161 TimeStampToken.
- **Trust Anchor Verification**: Compares root and intermediate certificates against the application-managed PKCS#12 keystore (`~/.oqteris/truststore.p12`).

## 5. Scope & Limitations

### In-Scope Features
- Viewing, continuous scrolling, page rotation, and zooming of standard PDF documents.
- Full-text search, outline navigation, and page thumbnail generation.
- Cryptographic digital signature validation and certificate trust management.
- Setting Oqteris as the default PDF viewer across Windows, Linux, and macOS.
- Single-instance IPC handling and command-line file opening.

### Out-of-Scope Features
- Non-PDF office formats (DOCX, XLSX, PPTX, RTF, ODT, ODS, ODP) are not supported. Oqteris is exclusively a dedicated PDF reader and editor.
- Audio/video multimedia playback embedded within PDF documents.
- Execution of embedded JavaScript within PDF forms (disabled for enterprise security).
